Automotive Waste Heat
Recovery System

A-WHRS is an ESP32-based prototype concept for monitoring thermoelectric generator (TEG) output and exploring adaptive control for automotive waste-heat energy harvesting.

ESP32 DevKit Arduino Framework / C++ TEG Monitoring MPPT — planned

Project objective

Monitor temperature, TEG voltage, and current using an ESP32. The readings can be used to estimate electrical output power and, after hardware validation, support a maximum power point tracking (MPPT) controller for a compatible DC-DC converter.

Key features

  • Analog sensor data acquisition
  • Voltage and current monitoring
  • Estimated power calculation: P = V × I
  • Temperature warning thresholds
  • Serial Monitor diagnostics

Example ESP32 pin mapping

  • GPIO 34: analog temperature sensor output
  • GPIO 35: TEG voltage measurement circuit
  • GPIO 32: current sensor output
  • GPIO 18: PWM reserved for future converter integration

Next development steps

  • Confirm the exact analog temperature sensor model.
  • Calibrate the voltage divider and current sensor.
  • Select a converter with a documented control interface.
  • Validate MPPT behavior on a current-limited bench setup.
  • Add independent overcurrent, overvoltage, and thermal protection.

Safety and prototype status

This page describes a prototype concept. The displayed sample values are fictional examples. Do not connect a raw 24 V signal directly to an ESP32 ADC pin. PWM is intentionally disabled in the monitoring example, and LOW or minimum duty cycle is not guaranteed to shut down every converter. Do not connect to a vehicle battery until the power stage, charging regulation, and independent protections have been designed and tested.
